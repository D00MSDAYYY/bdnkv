# Простой планировщик задач на C++20

```text
submit() → очередь задач → один из рабочих потоков → future.get()
```

Весь шаблон и пример использования находятся в `main.cpp`. Только стандартная библиотека.

```sh
cd thread-task-manager
clang++ -std=c++20 -pthread main.cpp -o task-manager
./task-manager
```

Пример выводит два раза `30`. Для GCC замените `clang++` на `g++`.

- `TaskManager(2)` создаёт два рабочих потока.
- `submit(lambda)` ставит задачу в очередь и возвращает `std::future` её результата.
- Аргументы задачи передавайте через захват лямбды.
- Рабочие потоки ожидают задачи без активного опроса; очередь защищена мьютексом.
- `future.get()` ждёт результат и пробрасывает исключение, если задача его выбросила. Это поведение обеспечивает `std::packaged_task`.
- Деструктор дожидается выполнения всей очереди и завершает потоки.

Это пул потоков с очередью FIFO. Порядок начала и завершения параллельных задач не гарантируется. Таймеров, приоритетов и отмены здесь нет.

Менеджер должен жить дольше всех обращений к нему; уничтожайте его из владеющего потока, когда другие потоки уже не вызывают `submit()`. Захваченные по ссылке данные должны существовать до окончания задачи. Не ждите из рабочих задач другие задачи этого же пула: при занятости всех потоков это может вызвать взаимную блокировку. Деструктор ждёт завершения задач, поэтому бесконечная задача не даст ему завершиться.
