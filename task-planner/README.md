# Порядок — шаблон планировщика задач

Самостоятельный адаптивный интерфейс на HTML, CSS и JavaScript. Без зависимостей, сборки и регистрации.

## Запуск

Откройте `index.html` в современном браузере. Для стабильного хранения данных рекомендуется локальный сервер:

```sh
cd task-planner
python3 -m http.server 8080
```

Откройте <http://localhost:8080>. Если порт занят, укажите другой.

## Возможности

- Создание, редактирование, выполнение и удаление задач. Для редактирования нажмите на название.
- Сроки, заметки, три приоритета и проекты «Работа», «Личное», «Обучение».
- Представления «Сегодня», «Предстоящие», «Все задачи», «Выполненные».
- Выбор дня, переход между неделями, поиск, сортировка и фильтры.
- Статистика за текущий день и прогресс выполнения.
- Сохранение в `localStorage`, синхронизация между вкладками одного адреса.
- Адаптация к телефону, работа с клавиатуры, подписи для экранного диктора.

При первом запуске появляются демонстрационные задачи. Они доступны для редактирования и удаления. Данные хранятся только в текущем браузере и не передаются на сервер. При смене адреса, порта или браузера хранилище будет другим. В приватном режиме и при открытии через `file://` сохранение зависит от настроек браузера; при ошибке появляется уведомление.

## Структура

- `index.html` — разметка, навигация и форма задачи.
- `styles.css` — оформление; основные цвета в `:root`, адаптивные правила в конце.
- `app.js` — модель задач, сохранение, фильтры и обработчики интерфейса. Проекты и приоритеты заданы в `PROJECTS` и `PRIORITIES`; для изменения вариантов также обновите навигацию и поля формы в HTML.

Статистика всегда относится к сегодняшнему дню. «Предстоящие» показывает незавершённые задачи со сроком позже сегодня. Просроченные задачи и задачи без срока доступны в разделе «Все задачи». Нажатие на день недели открывает задачи на выбранную дату. При сохранении задачи открывается её день, а для задачи без срока — «Все задачи».

Проверка синтаксиса JavaScript:

```sh
node --check app.js
```
